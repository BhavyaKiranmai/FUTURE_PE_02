# Project Summary

## Project Title

AI Content Marketing Using UGC Ads

## Product

GlowSkin Face Wash

## Objective

To create AI-generated User Generated Content (UGC) advertisements for a skincare product using prompt engineering techniques.

## Target Audience

Men and Women aged 18-35 interested in skincare solutions.

## Deliverables Created

* 20 UGC Hooks
* 5 UGC Ad Scripts
* 20 CTAs
* Instagram Captions
* Facebook Captions
* YouTube Shorts Captions
* Platform-Specific Versions
* Prompt Documentation

## Tools Used

* ChatGPT
* VS Code
* GitHub

## Outcome

Successfully created a complete AI-generated UGC advertising package for a skincare product.
